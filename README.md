README.md

This project focuses on building predictive models to classify insurance claims as fraudulent or legitimate using real-world claim data. The goal is to improve fraud detection, reduce manual investigations, and support faster, more reliable decision-making for insurance companies.
Business Objective
Global Insure seeks to proactively detect potentially fraudulent insurance claims before approval. The aim is to reduce financial losses, streamline investigations, and improve customer satisfaction through early fraud identification.
Process Overview
Data Preparation

Loaded and cleaned historical insurance claims data.

Fixed null values, invalid entries, and data types.

Exploratory Data Analysis (EDA)

Identified key trends and patterns associated with fraud.

Addressed class imbalance using oversampling.

Feature Engineering

Created new features.

Encoded categorical variables and applied feature scaling.

Model Building

Logistic Regression (with feature selection and optimal cutoff tuning).

Random Forest (with hyperparameter tuning).

Model Evaluation

Evaluated models on unseen validation data.

Compared key metrics: Accuracy, Sensitivity, Specificity, Precision, and F1-Score.
